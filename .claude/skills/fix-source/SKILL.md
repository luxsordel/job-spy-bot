# Починка площадки: $ARGUMENTS

## 1. Что сломалось

1. Открытый issue ночной проверки:
   ```bash
   gh issue list --state open --search 'in:title "Ночная проверка"' --json number,title,body
   ```
   Из тела issue возьми сломанные площадки и тип сбоя («недоступна», «ошибка», «пустая
   выдача»). Если аргумент не задан и сбоев несколько — спроси, с какой начать.
2. Воспроизведи локально:
   ```bash
   python -X utf8 -m jobspybot --env /dev/null check-sources --strict "python developer"
   ```
   (на Windows вместо `/dev/null` — `NUL`). Если локально всё работает — сбой был временным:
   сообщи пользователю и предложи закрыть issue, ничего не меняя.

## 2. Диагностика

Прочитай `src/jobspybot/sources/<name>.py` и сравни ожидания парсера с живым ответом
(запроси ту же страницу, что и `search`, тем же способом — один запрос, честный User-Agent).
Типичные причины:
- **403 / капча / Cloudflare** — не обходить. Площадка должна бросать `SourceUnavailable`;
  сообщи пользователю, что площадку, возможно, придётся отключить.
- **Сменились поля JSON или селекторы HTML** — обнови парсер.
- **Сменился URL или параметры API** — обнови запрос.
- **Пустая выдача по запросу** — проверь, не изменилась ли сортировка или фильтр по дате.

## 3. Исправление

1. Обнови парсер так, чтобы он был терпим к отсутствующим полям.
2. Обнови фикстуру `tests/fixtures/<name>_*` по **новому** живому ответу: урежь до 2–3
   вакансий, обезличь персональные данные.
3. Поправь тест в `tests/test_sources.py` (или `test_source_hh.py` для hh), если изменились
   ожидаемые значения. Добавь проверку на то поле, которое сломалось.

## 4. Проверки

```bash
ruff check . && ruff format --check .
pytest -q
python -X utf8 -m jobspybot check-sources --strict "python developer"
```

## 5. Оформление

Ветка `fix/source-<name>`, коммит `fix(sources): <что изменилось на площадке>`, в PR —
`Closes #<номер issue>`. Коммит и PR — только по просьбе пользователя.
