## [1.1.0] — не выпущена

### Добавлено
- Тарифы Free / Pro, пробный Pro для новых пользователей, оплата Telegram Stars
  с автопродлением, отмена автопродления, напоминания об окончании подписки.
- Открытая регистрация (`ACCESS_MODE=open`) в дополнение к приглашениям.
- Профиль соискателя: ИИ заполняет его из резюме, бот спрашивает только недостающее
  и сам настраивает поиск; раздел «👤 Профиль» с правкой кнопками; профиль — контекст
  для ИИ-оценки и писем.
- Формат работы (удалёнка / гибрид / офис) и адрес с метро из данных площадок; фильтры
  «только мой город» и «скрывать без формата»; пожелания текстом (район, метро) для ИИ;
  правка профиля обычной фразой с подтверждением.
- Главное меню, фильтры кнопками, экран подписки, описание бота.
- Админка: `/admin` с выручкой, `/grant`, `/refund`.
- Веб-админка (вне Telegram): обзор с воронкой, расходом ИИ и здоровьем площадок,
  пользователи с действиями, приглашения, рассылка по сегментам.
- Несколько грейдов сразу в профиле и анкете (например, Junior + Middle).
- Проверка профиля после разбора резюме ИИ: «Вот что я понял» с кнопками правки
  до запуска поиска.
- Защита от злоупотреблений: лимит сообщений в минуту и файлов в сутки, `/ban`, `/unban`.
- `/privacy` и `/delete_me`: политика конфиденциальности и удаление своих данных;
  автоудаление данных неактивных пользователей.
- Оповещения админу: ошибки, молчащие площадки, сбои ИИ-провайдера, перезапуск.
- Веб-админка: логи, правка настроек, перезапуск бота и JSON-API по токену — управление
  без SSH; в карточке пользователя — последние вакансии и причины отсева.
- Отбор по роли: вакансии другой профессии (бизнес-аналитик, продажи, поддержка для
  разработчика или тестировщика) отсеиваются до ИИ, даже если в тексте есть «AI» или «Python».

### Исправлено
- Нереалистично большая зарплата ломала бота (`OverflowError`); теперь ввод
  ограничен 50 000 $, а уже сохранённые битые значения чинятся при чтении.
- Вакансии уходили без оценки ИИ, когда кончался дневной лимит токенов или резюме не
  разобрано: теперь без ИИ присылается только то, где роль совпадает по названию, а ИИ
  оценивает по профилю, если резюме нет, и знает, какие роли человек ищет.
- Снятый в фильтрах грейд (и страна, и зарплата) возвращался после любой правки профиля.
- Длинные списки и строки (стоп-слова, направления, город) обрезаются до разумных размеров;
  числа с «²» и другими юникод-цифрами больше не роняют обработчики.

### Изменено
- HeadHunter (rabota.by, hh.ru, hh.kz) читается со страниц сайта вместо API: анонимный
  доступ к API закрыт, а регистрировать приложение не нужно. `HH_APP_TOKEN` больше не нужен.
  Почасовые и посменные ставки hh не считаются месячной зарплатой.

## [1.0.0] — 2026-11-19

Полное переписывание с Java на Python ради работы на VPS с маленьким объёмом памяти.

### Добавлено
- 10 площадок: rabota.by, praca.by, hh.ru, Habr Карьера, GetMatch, SuperJob, hh.kz, jobs.ge,
  justjoin.it, No Fluff Jobs.
- Бесплатный первичный отсев: стоп-слова, обязательные слова, уровень, страна, удалёнка,
  зарплата в $, дедупликация между площадками, локальный скоринг по навыкам.
- Многопользовательский Telegram-бот с доступом по инвайтам.
- ИИ-оценка через любой OpenAI-совместимый API: профиль из резюме, балл и плюсы/минусы,
  доступность для граждан РБ, сопроводительное письмо по кнопке. Кэш и дневной лимит токенов.
- Несколько резюме (PDF / TXT / текст, до 10): ИИ одним запросом выбирает лучшее под
  вакансию; кнопка «Отклик» присылает это резюме и письмо под него. Отсев по навыкам
  считается отдельно для каждого резюме.
- Деплой через systemd + venv с ограничением памяти.
- CI: ruff + pytest.

### Удалено
- Java-прототип (сохранён под тегом `java-prototype`).
